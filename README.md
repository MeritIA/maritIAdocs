# MeritIA · Documentación

Sitio estático responsive publicado con GitHub Pages desde la raíz de `main`.

- **Sitio:** https://meritia.github.io/maritIAdocs/
- **Fuentes documentadas:** `MeritIA/web`, `MeritIA/backend`, `MeritIA/ai-service` y `MeritIA/rag-service`.
- **Contenido:** frontend, arquitectura, backend, IA, RAG, privacidad y leyes, requisitos, operación, decisiones y estado del proyecto.
- **Diagramas:** Mermaid local, sin dependencia de un servicio externo.

Para actualizar GitHub Pages, publica los archivos HTML y `assets/` en la raíz de `main`. La configuración de Pages debe apuntar a `main` y `/`.

El estado y las cifras reflejan el corte indicado en cada página; revisa especialmente `estado.html` antes de reutilizarlos como información actual.
